# 认证与授权作用域

**代码**：`auth/token.py`（签发与校验）· `auth/password.py`（运营密码）·
`api/auth.py`（路由）· `api/deps.py`（两个身份依赖）· `tests/test_auth_*.py`

**范围出处**：[前端接入与认证方案](../design/2026-08-21-client-auth.md) · 里程碑 D9

## 一句话职责

回答「**谁在调**」和「**他能看到哪一部分数据**」，不回答「他能做什么」——
后者是路由分组决定的：内部接口挂运营身份，`/api/portal/*` 挂客户身份且只读。

**不负责**：用户管理（注册、改密码、角色权限一律不做）、token 撤销、微信授权登录。
理由都在[设计文档第八节](../design/2026-08-21-client-auth.md)。

## 接口

| operationId | 路径 | 说明 |
|---|---|---|
| `login` | POST `/api/auth/login` | 运营登录，**免认证** |
| `refreshToken` | POST `/api/auth/refresh` | 运营续期，要未过期的运营 token |

## 能读文档就够的部分

| 规则 | 一句话 |
|---|---|
| 两种身份 | `operator`（运营，全部内部接口）与 `client`（客户，只读且只看自己） |
| 有效期 | 运营 8 小时；客户端 7 天 |
| 客户端滑动过期 | 未过期时可换新的，**绝对上限 90 天**，从首次签发算起、续期不重置 |
| 运营续期 | 未过期时可换新的，没有绝对上限（重新登录即可） |
| 免认证的接口 | 只有两个换 token 的入口，加上健康探针。清单以 `tests/test_auth_guard.py` 的豁免表为准 |
| 401 的响应体 | 固定一句话，**不说明是没带、无效、过期还是拿错了门** |
| 运营账号从哪来 | 环境变量（`OPERATOR_USERNAME` + `OPERATOR_PASSWORD_HASH`），**不建用户表**，多人共用一个账号 |
| 没配 `AUTH_SECRET` 时 | 登录返回 **503**（部署方的问题），不是 401 |
| 生产环境 | `ENVIRONMENT=prod` 且认证没配齐时**进程直接起不来** |

## ⛔ 必须读源码的部分

- **`auth/token.py` 里步骤的顺序就是安全性本身。** 签名比对必须
  `hmac.compare_digest`、验签必须排在解析和过期判定之前、验的必须是收到的原始
  字节、`scope` 必须比对。这四件事**错了都不会报错**，只会悄悄放行 —— 看签名
  推不出来，测行为也测不出来（`tests/test_auth_token.py` 最后那条只能去扫源码
  结构）。改这个文件之前先读它的模块 docstring。

- **运营密码校验是 CPU 密集的，必须走 `asyncio.to_thread`。** argon2 一次几十
  毫秒是它的功能不是缺陷，而在 `async def` 里直接调会卡住整个事件循环 ——
  症状是**全局变慢**，不是登录变慢。照 `api/auth.py` 的 `login` 抄。

- **两处哈希故意不一样**：运营密码用 argon2（慢，抵消人类密码的低熵），邀请码
  用 SHA-256（192 位随机串，慢哈希防不住任何本来防得住的攻击）。看到「这里怎么
  没统一」时，先读 `auth/password.py` 的模块 docstring。

## 已知残余

- 🔴 **token 撤销不了。** 自包含 token 一旦签出去，在过期之前一直有效。想立刻
  切断只有两个手段：把那个客户置 `is_active=False`（客户端 token 每次请求都会
  查这一条，见 `api/deps.py`），或者改 `AUTH_SECRET`（**所有人一起失效**）。
  单个运营 token 没有任何撤销办法，最多活 8 小时。
  MVP 接受这个代价 —— 换成「每次请求查一遍库」要为它引入一张会话表和一次额外
  查询，而这个系统的访问量是「几个客户每天看几次」。

- **登录接口没有限流。** argon2 本身几十毫秒是天然限速，而运营账号只有一两个人
  用。真要加就是 Redis 计数器（基础设施现成），加在 `api/auth.py` 的 `login`。

- **多人共用一个运营账号**，所以操作记录里分不出「谁改的」。这是范围取舍不是
  遗漏，见设计文档第五节。
